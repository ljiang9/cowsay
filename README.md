# cowsay

会说话的牛：把文字装进对话框，让 ASCII 动物说出来。纯标准库、纯本地。

> **原创声明**：本项目的牛/猫/机器人 ASCII 艺术均为手绘原创，
> 不是经典 `cowsay` 的那头牛（`(oo)\_______` 那头）。

## 安装

零依赖，Python 3.10+：

```bash
cd cowsay
python3 -m cowsay "你好，世界！"
```

## 用法

```bash
cowsay "hello"                 # 牛说话
cowsay --animal cat "喵"        # 猫说话（cow / cat / robot）
echo "管道输入" | cowsay --stdin
cowsay --width 20 "很长的话会自动换行……"
cowsay --list-animals           # 列出可用动物
```

示例输出：

```
 _______________
< 你好，世界！  >
 ---------------
   \   .-"-.
    \ ( o o )
      |  ~  |
      | ___ |
       \___/
      _|   |_
     |_|   |_|
```

## 设计说明

- **宽度计算**：CJK（中日韩）字符按 2 个英文字符宽度计
  （`unicodedata.east_asian_width` 为 `W`/`F` 的字符），
  否则中文会导致对话框边框错位。换行优先按空格断词，
  超长词（或无空格的中文长句）按字符硬断。
- 对话框上边框用 `_`、下边框用 `-`，单行用 `< >`，
  多行首尾用 `/ \`、`\ /`，中间用 `| |`。

## 已知局限

- 只做纯文本对话框，不支持彩色/emoji 宽度微调
  （emoji 的终端显示宽度因字体而异，可能错位 1 格）。
- 动物只有 3 只，艺术是手绘极简风，别指望像素画。
- `--width` 最小 10；空输入会报错而不是画一个空泡泡。
